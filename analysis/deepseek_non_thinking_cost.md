# DeepSeek 统一关闭思考模式：费用敏感性

核查日期：2026-10-15。范围是一个外部 DeepSeek 受测模型完成 SWE 51、Terminal 89×5=445、ASI 60×4=240、HLE 2500 次任务；不是本题 Qwen Base／专家／合版的评测矩阵。此次只核查公开资料和已有预算，没有付费 API 调用或正式评测。是否调整正式 thinking 协议应另行确认，本文件不替代协议冻结。

## 官方计费规则

DeepSeek 当前 Flash 的非思考与思考模式使用同一张价格表。空闲时段每百万 token：输入缓存命中 0.02 元、输入未命中 1 元、输出 4 元；高峰各项为 2 倍。关闭思考不会切换到更低单价，省费来自实际输入／输出 token 数减少。[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

OpenAI Chat Completions 格式通过 `thinking.type=disabled` 关闭；使用 OpenAI Python SDK 时放入 `extra_body={"thinking":{"type":"disabled"}}`。默认是启用思考。携带 tools 的思考调用会回传历史 `reasoning_content` 并计入上下文，因此关闭思考可能同时影响后续累计输入；不携带 tools 的历史思考本来就不会拼接。[官方思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)

预算的 completion 总数已经包含 reasoning，不应先按 completion 计费后再加 reasoning 一次。非思考模式仍可能在普通 `content` 中写解释、分析或计划，也仍会输出命令／代码；不能把关闭 thinking 当成只付最终一句答案的费用。

## 只改变输出的可审计情景

沿用 [此前中情景](deepseek_cost_estimate.md) 的任务数与累计输入：SWE 每次 1M、Terminal／ASI 每次 0.5M、HLE 每次 2K。三项 agent 的输入缓存命中暂设 70%，HLE 0%；合计输入 398.5M，其中 hit 275.45M、miss 123.05M，空闲输入费固定 128.559 元。此前累计输出 43.1M（含思考），空闲输出费 172.4 元，总作答费 300.959 元。

为隔离关闭思考的输出影响，下面分别假设新累计输出是此前预算的 25%／50%／75%。这是敏感性分析，不是已知的非思考平均 token，也不保证某个固定节省比例。保持输入不变也不是实际用量上限：工具轮数、失败重试和缓存都会变化。

| 输出假设 | 总输出 token | Flash 空闲作答费 | 全部高峰作答费 | 完全无缓存：空闲 | 完全无缓存：高峰 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 变为此前 25% | 10.775M | ¥171.66 | ¥343.32 | ¥441.60 | ¥883.20 |
| 变为此前 50% | 21.550M | ¥214.76 | ¥429.52 | ¥484.70 | ¥969.40 |
| 变为此前 75% | 32.325M | ¥257.86 | ¥515.72 | ¥527.80 | ¥1055.60 |
| 原思考预算参考 | 43.100M | ¥300.96 | ¥601.92 | ¥570.90 | ¥1141.80 |

计算式：空闲 Flash = `275.45×0.02 + 123.05×1 + 43.1×输出比例×4`。无缓存列把 398.5M 输入全部按 1 元／M 计。

例如“输出变为原来 50%”时的逐项空闲费用为 SWE ¥21.114、Terminal ¥96.565、ASI ¥52.080、HLE ¥45.000，总计 ¥214.759。

因此讨论时可以说：在此前输入与缓存假设成立、输出降到原预算 25%–75% 的情景下，四项一个 DeepSeek 模型的作答费约空闲 ¥172–258、全部高峰 ¥343–516；取“输出减半”的计算点是约 ¥215／¥430。不能把这个区间写成实测预测或封顶预算。若缓存失效，所列同一情景约空闲 ¥442–528、全部高峰 ¥883–1056。

## 尚未包含的部分与协议差异

- CPU／容器／编译测试／科研执行资源费用不在本表内；关闭模型思考不会减少每个沙箱所需的固定资源配置。
- HLE Judge 另算；此前占位估计空闲 ¥10.5–35，全部高峰 ¥21–70。ASI 官方 GPT-5.5／图文 Judge 仍需原服务凭据与费用，不能以 DeepSeek 作答费替代。
- 关闭思考可能减少生成等待，也可能增加命令错误、工具轮数与重试；未测前不能把 token 缩短比例等同于全流程时间缩短比例。
- 官方当前文档说明非思考模式 `top_p` 固定为 1.0，传入值被忽略；思考模式下 `temperature` 被忽略、`top_p` 有效范围为 0.95–1.0。故关闭 thinking 仍无法声称完整对齐题定 Terminal 的全部采样参数。[官方参数规则](https://api-docs.deepseek.com/guides/thinking_mode/)
- 当前 Flash 支持图像，Pro 不支持；此处始终按统一 Flash 计价。DeepSeek 外部参考结果不替代本题要求的 Qwen 权重评测。
